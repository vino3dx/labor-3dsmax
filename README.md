# 🚀 MaxKit Professional Toolkit - 3ds Max Workflow Essentials

**[🇨🇳 点击此处查看中文简介 (Click Here for Chinese Introduction)](#中文简介)**

**MaxKit** is a professional MaxScript utility designed for 3ds Max users. It simplifies complex material management and object alignment tasks, significantly enhancing your daily production workflow and efficiency.

## ✨ Key Features

### 1. Material Utilities

| Feature | Description |
| :--- | :--- |
| **Convert Materials** | One-click conversion between **Standard** and **VRay** materials for selected objects or the entire scene, preserving maps and key parameters. |
| **Random Material** | Quickly apply a **Standard Material** with a randomized color to selected objects for fast differentiation. |
| **Wire Color Material** | Creates and applies a material that matches the selected object's **wireframe color**, often used for ID pass rendering. |
| **Toggle Texture Display** | Easily toggle the display state of textures in the Material Editor for performance optimization. |

### 2. Model Tools

| Feature | Description |
| :--- | :--- |
| **Sequential Object Alignment** | Aligns multiple selected objects sequentially along the **X / Y / Z axis**. Supports Bounding Box (BBox) precision and custom offsets. |

## ⬇️ Download and Installation

1.  Download the **MaxKit.mcr** or **MaxKit.ms** script file.
2.  Drag the file into the 3ds Max viewport, or execute it via the Scripting menu.
3.  Go to **Customize User Interface**, find the **MaxKit** category, and assign the **MaxKit Professional Toolkit** command to a toolbar or shortcut.

## 中文简介

**MaxKit 专业工具集** 是一套为 3ds Max 用户设计的 MaxScript 脚本，旨在简化材质处理和模型对齐等繁琐的日常工作，显著提高您的制作效率。

### 插件功能

* **材质转换:** 一键将场景或选中对象的**标准材质**转换为 **VRay 材质**，或反向转换，支持贴图和主要参数的映射。
* **随机材质:** 为选定对象快速应用具有随机颜色的**标准材质**，便于区分和查看。
* **线框颜色材质:** 为选定对象生成并应用与其**线框颜色**一致的材质，常用于渲染 ID 通道。
* **切换纹理显示:** 快速切换材质球（材质编辑器中）的贴图显示状态。
* **模型对齐:** 沿 **X / Y / Z 轴**将多个选定对象**顺序对齐**，支持使用边界框 (BBox) 进行精确计算，并可设置偏移量。

### 安装方法

1.  下载 **MaxKit.mcr** 或 **MaxKit.ms** 文件。
2.  将文件拖拽到 3ds Max 视窗中，或通过“脚本”菜单运行。
3.  在 **自定义用户界面** 中，找到 **MaxKit** 类别，将 **MaxKit 专业工具集** 拖动到工具栏或指定快捷键。
